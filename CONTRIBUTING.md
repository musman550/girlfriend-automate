# Contributing

Thanks for helping! Good first contributions: translations, UI polish, bug fixes, new safety options.

1. Fork the repo and create a branch.
2. Open in Android Studio (Koala or newer), or run `gradle :app:assembleDebug`.
3. Keep changes small and focused. Do not remove the built-in AI label from replies.
4. Open a pull request and describe what you tested on a real device.

Never commit API keys or keystores.
